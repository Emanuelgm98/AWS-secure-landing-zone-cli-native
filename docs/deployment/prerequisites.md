# Future deployment prerequisites

Deployment is outside this task. Before any implementation: approve account ownership and Organizations enrollment; confirm delegated administrators, service access, AWS Config service-linked roles, CloudTrail organization prerequisites and destination bucket policy; select regions and test quotas; allocate globally unique archive name; decide KMS key policy, retention/Object Lock, replication and recovery; define Identity Center identity source/groups/assignments; choose remote state encryption, access control, locking and recovery; pin Terraform/provider versions from an approved source; inspect SCP impact and emergency access; agree change review, cost limits, evidence retention and rollback owners. Populate IDs only through protected operator inputs. No fake IDs or secrets belong in version control.
