# Recovery and controlled destruction

No infrastructure is deployed by this repository. For future recovery, preserve Terraform state and CloudTrail/Config evidence, validate state backups and KMS access, restore the log archive before dependent audit services, and use approved break-glass access. Destruction is especially sensitive: `prevent_destroy` protects selected archive resources and organization accounts, but is not a universal safety guarantee. Do not remove protections as a routine step. Require explicit account/data-owner approval, retention/legal-hold review, verified evidence export and restore, dependency inventory, reviewed plan and independent approval. Destroy workload/member resources before security controls only under a documented migration plan. Never destroy organization or archive evidence to resolve a routine drift issue.
